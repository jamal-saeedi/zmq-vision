# Archived original scripts

These four scripts preserve the original 2024 implementation for historical reference. They are not entry points for the current package, are excluded from supported checks, and use the older `_rid` / `preds` wire format.

Use `zmq-vision serve`, `zmq-vision infer`, and the Python clients instead. Do not combine these scripts with the current protocol. Original label data now lives in `src/zmq_inference/data/`; the sample image lives in `examples/sample.png`.
