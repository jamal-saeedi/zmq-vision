# ZMQ Inference 0.5.0 — Vision-language models and a local dashboard

The new CPU VLM backend serves SmolVLM-256M Instruct and a matching GGUF projector. Call `generate(prompt, image=...)` in either Python client or add `--image` to the CLI. The same VLM server also accepts text-only prompts.

The new browser dashboard sends real requests through the existing ZeroMQ transport. It displays classifier scores, generated answers, token usage, and recent processing times.

```bash
python -m pip install --upgrade "zmq-vision>=0.5.0"
zmq-inference web --demo
```

Open http://127.0.0.1:8080 to run a classifier demo with no weights. The project display name is now **ZMQ Inference**. Installation still uses `zmq-vision`, Python uses `zmq_inference`, and both CLI names remain available.
