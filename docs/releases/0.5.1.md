# ZMQ Inference 0.5.1 — Connect the dashboard to SmolVLM

The dashboard now detects the connected backend's tasks. The download-free classifier enables **Classify**. SmolVLM enables **Ask image** and **Generate**.

Start the dashboard and a local VLM together with `zmq-inference web --vlm --model-path smolvlm.gguf --projector-path projector.gguf`. The existing `web --demo` command still launches the download-free classifier.

[Model and projector download instructions](https://github.com/jamal-saeedi/zmq-vision/tree/v0.5.1#ask-a-question-about-an-image)
