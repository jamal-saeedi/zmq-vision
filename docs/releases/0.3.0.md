# ZMQ Vision 0.3.0

A standalone image inference library with a lightweight core, optional PyTorch and TensorFlow backends, and clients for synchronous and asyncio applications.

- New `zmq-vision` CLI with `demo`, `doctor`, `serve`, `infer`, and inference-free `health` commands.
- Installable `src/` package, one dependency source, bundled labels, MIT license, wheel and source distributions.
- Bounded model work, validated messages and images, explicit overload responses, startup failure propagation, and cleanup of sockets and workers.
- Correlated client responses, bounded retries, timeout recovery, and cancellation-safe async exchanges.
- Model-specific timm preprocessing and current TensorFlow/Keras model calls.
- Real TCP regression tests, optional real-model tests, and a reproducible download-free demo.

Read [migration notes](https://github.com/jamal-saeedi/zmq-vision/blob/main/docs/migration.md) for changed defaults and archived script locations. Pushing a version tag runs release checks and creates a GitHub release; PyPI publication is a separate manual step.
