# ZMQ Vision 0.4.0 — Local LLMs and faster ZeroMQ responses

Serve a small language model on CPU with `zmq-vision[llm]` and local GGUF weights. Send a prompt through the new `generate` command or either Python client. The response includes generated text, token counts, and the reason generation ended.

The vision demo's single-client p95 fell from 56.5 ms to 3.3 ms on the same WSL2 machine after shortening the completion poll. With SmolLM2-135M Instruct, one client received about 98 output tokens per second using two CPU threads. See the [benchmark results](https://github.com/jamal-saeedi/zmq-vision/blob/v0.4.0/docs/benchmarks.md) for the workloads, reproduction commands, and the four-client MobileNet tradeoff.

```bash
python -m pip install zmq-vision==0.4.0
zmq-vision demo
```

The wheel in the release assets can also be installed directly with `python -m pip install zmq_vision-0.4.0-py3-none-any.whl`.

The existing image requests, `zmq_inference` imports, and `zmq-inference` CLI alias continue to work. The base install needs no model runtime. The [quick start](https://github.com/jamal-saeedi/zmq-vision/tree/v0.4.0#quick-start) covers the core demo, local generation, and image classification.

Local validation passed 110 tests, including pretrained PyTorch and TensorFlow MobileNet inference and real GGUF generation over TCP. Clean wheel installs passed the download-free demo and both LLM CLI client modes.
